# Homebrew Tap for Superghost

This is the official Homebrew tap for [Superghost](https://github.com/matt-ramotar/superghost), a Ghostty-based macOS terminal with vertical tabs for AI coding agents.

## Installation

```bash
brew tap matt-ramotar/homebrew-cmux
brew install --cask superghost
```

## Updating

```bash
brew upgrade --cask superghost
```

## Uninstalling

```bash
brew uninstall --cask superghost
brew untap matt-ramotar/homebrew-cmux
```
